# KAR Projects Universe

Portfolio / hub de présentation des projets de `anormadaise2-ops`.

## Fonctionnalités
- Three.js / WebGL
- Particules 3D
- Objet wireframe animé
- Interaction souris
- Glassmorphism
- Motion design
- Recherche et filtres
- Chargement automatique des dépôts GitHub
- Liens GitHub + déploiements live
- Responsive desktop / mobile

KAR AI et KAR Vault sont exclus de la liste.

## Déploiement
Le projet est statique : ouvre `index.html` ou déploie le dossier sur GitHub Pages / Netlify / Vercel.
